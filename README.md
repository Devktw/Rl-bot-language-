# ฟุตบอล 2v2: จะเกิด "ภาษา" ขึ้นเองไหม

ฟุตบอล 2v2 บน grid 2 มิติ ผู้เล่นมองเห็นได้จำกัด (รัศมี 2 ช่อง) และส่ง token จากคำศัพท์ 8 ตัวหาเพื่อนร่วมทีมได้ทุก step
เทรนด้วย PPO โดยไม่มี gradient ผ่านช่องสื่อสาร ภาษาจึงต้องเกิดจาก reward เพียงอย่างเดียว
คำถามหลักคือ ถ้าคู่แข่ง **ดักฟังได้** จะเกิดรหัสลับหรือไม่

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `football/env.py` | env แบบ vectorized ใช้ team frame (ทุกทีมบุกไปทางขวา), action: เดิน 4 ทิศ/อยู่นิ่ง/ส่ง/ยิง + token |
| `football/agent.py` | actor ร่วมในทีม + centralized critic |
| `football/scripted.py` | บอทเขียนกฎ เห็นทั้งสนาม ใช้เป็นคู่ซ้อมที่นิ่ง |
| `train.py` | PPO; `--cond` เลือกเงื่อนไข, `--opponent scripted` ให้ซ้อมกับบอท |
| `analyze.py` | MI signaling/listening, intervention (สลับ token เป็นค่าสุ่ม), lexicon heatmap, drift |

เงื่อนไข (`--cond`): `nocomm`, `asym` (แดงคุยได้ น้ำเงินใบ้), `private`, `eavesdrop` (ทุกคนได้ยินทุกคน), `spy` (น้ำเงินแอบฟังแดง)

```bash
pip install -r requirements.txt
python -m pytest -q tests
python train.py --cond private --updates 400          # ~20 นาที / CPU 1 คอร์
python analyze.py runs/private_s0                      # ผลจะอยู่ที่ results/private_s0/
```

## ผลการทดลอง (seed 0, 6.5M steps ต่อ run)

### รอบ 1: self-play สองทีม
| เงื่อนไข | win แดง/น้ำเงิน | MI(token; สถานการณ์) แดง | win แดงเมื่อสลับ token ของแดงเป็นค่าสุ่ม |
|---|---|---|---|
| nocomm | 0.36 / 0.37 | 0.044 (ระดับ noise) | – |
| asym | 0.35 / 0.43 | 0.054 | 0.35 |
| private | 0.35 / 0.28 | 0.036 | 0.34 |
| eavesdrop | 0.33 / 0.36 | 0.036 | 0.32 |

**ยังไม่เกิดภาษา:** MI อยู่ระดับเดียวกับ nocomm และเมื่อสลับ token เป็นค่าสุ่ม win rate ไม่เปลี่ยน
อีกปัญหาคือ self-play แกว่งแรง (win rate กระโดดระหว่าง 0.15–0.6) จนกลบประโยชน์เล็กๆ ของการสื่อสาร

### รอบ 2: แดงซ้อมกับบอท scripted ที่นิ่ง
| run | win แดง | MI(token; สถานการณ์) | win เมื่อสลับ token |
|---|---|---|---|
| nocomm (เห็น 2 ช่อง) | 0.967 | 0.040 | – |
| **oracle** (เห็นทั้งสนาม, ไม่คุย) | 0.966 | – | – |
| asym (คุยได้) | 0.960 | 0.020 | 0.965 |
| asym, entropy ของ token ต่ำ | 0.961 | **0.332** | 0.955 |

- **ข้อค้นพบสำคัญ:** ทีมที่ "เห็นทั้งสนาม" ไม่ได้เก่งกว่าทีมที่เห็นแค่ 2 ช่อง แปลว่า**ข้อมูลที่ซ่อนอยู่แทบไม่มีค่าในเกมนี้**
  agent ชนะได้ด้วยการเลี้ยงบอลเดี่ยวแล้วยิง (แทบไม่ส่งบอลเลย) จึงไม่มีแรงกดดันให้ต้องคุยกัน
- ในรุ่นที่ entropy ของ token ต่ำ token 3 มีความหมายราวกับ "ฉันถือบอล" (MI 0.33 bit; ดู `results/asym_vs_bot_lowent_s0/lexicon.png`)
  แต่เมื่อสลับเป็นค่าสุ่ม win rate ไม่ตก คือ**มีการส่งสัญญาณแต่ไม่มีใครใช้มัน** ยังไม่นับว่าเป็นภาษา

### บทเรียน
ก่อนจะหวังให้เกิดภาษา ต้องออกแบบเกมให้มี **oracle gap** ก่อน คือทีมที่เห็นทั้งสนามต้องชนะทีมที่เห็นจำกัดได้ชัดเจน
ถ้าไม่มีช่องว่างนี้ การสื่อสารก็ไม่มีประโยชน์ให้เรียนรู้
